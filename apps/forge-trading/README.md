# Forge Trading — standalone vertical

Static PWA: no build step, no backend. Serve the folder as-is (`python3 -m http.server`) or drop into `apps/forge-trading/` in the monorepo.

- `bank.json` — 120 terms, 90 scenarios, generated by `build_bank.py` from the two Markdown banks in `content/`. Re-run after editing content: `python3 build_bank.py`
- `app.js` — four modes: Terms (flashcards), Say it (typed articulation, 4-box spacing), Scenarios (four-option, rationale on reveal), Progress (per section). Progress lives in `localStorage` under `forge-trading:v1`.
- `sw.js` — caches the shell and bank for offline drills.

To bring it in line with the other verticals: replace the mode components with the shared package equivalents, swap `localStorage` for the Supabase profile/credits ledger, and add the WebLLM tutor. The bank JSON shape (`terms[]`, `scenarios[]` with `options[4]`, `answer` index, `rationale`) matches the gauntlet's normalized schema.
